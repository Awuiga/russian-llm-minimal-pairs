# Методика эксперимента

[К результатам и запуску](../README.md)

## Дизайн

1. Шаблонно-словарный генератор создаёт пары из правильного предложения и его версии с контролируемой ошибкой. Ручная проверка отбирает пары для финального корпуса.
2. Правильные и ошибочные предложения подаются модели отдельно. Корпус сбалансирован, на каждую ошибочную фразу приходится одна правильная.
3. Для каждого предложения проходят все шесть моделей и три промпта. `direct_zero_shot` даёт прямую инструкцию, `minimal_edit` требует минимального вмешательства, `step_by_step` задаёт пошаговую проверку. Точные формулировки в [prompts.py](../prompts.py), параметры в [конфигах](../configs/).
4. Парсер приводит ответы к общему формату. Метрики вычисляются по одной строке на комбинацию предложения, модели и промпта. Срезы включают модель, провайдера, промпт, правило, сложность и тип варианта.

## Что означают метрики

| Метрика | Как считается |
| --- | --- |
| Detection accuracy | Верные решения о наличии ошибки / все ответы |
| Correction accuracy | Ошибка отмечена и исправление совпало с эталоном / все ошибочные предложения |
| False-positive rate (FPR) | Правильное предложение помечено ошибочным / все правильные предложения |
| False-negative rate (FNR) | Ошибочное предложение принято как правильное / все ошибочные предложения |
| Exact match | Совпадения итоговой фразы с эталоном на ошибочных предложениях / все ошибочные предложения |
| Exact match (all) | Совпадения с эталоном / все предложения |
| Exact match (correct) | Совпадения с эталоном на правильных предложениях / все правильные предложения |

Exact match сравнивает нормализованные строки. Correction accuracy дополнительно требует верного флага об ошибке. Поэтому на v4 у этих двух метрик числители различаются: **1 285** и **1 284** из 1 440. В v4 у всех 2 880 строк есть распознанный статус ответа, 100 правильных предложений помечены ошибочными, 81 ошибка пропущена. [Числители и знаменатели](../reports/metrics_audit_final/02_independent_metric_audit.csv)

## Как читать сравнения

- Результаты описывают конкретные снимки моделей, промпты и синтетический корпус. Проверка на естественных текстах потребует отдельного корпуса.
- Версии различаются составом и размером. Таблица по v1–v4 показывает, как менялись метрики на проверенных наборах, и не изолирует влияние размера корпуса.
- Модели и промпты внутри одной версии оценивались на одних и тех же предложениях. Строки матрицы повторяют предложения и пары, поэтому 2 880 результатов представляют 160 уникальных входов v4.
- Точное совпадение может засчитать допустимое альтернативное исправление как ошибку. Оно измеряет соответствие одному текстовому эталону.
